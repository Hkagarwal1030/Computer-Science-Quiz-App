# Computer-Science-Quiz-App
🎯 Computer Science Quiz App












A sleek, interactive quiz application that fetches real-time Computer Science questions from the OpenTDB API.
It includes animated feedback, score evaluation, accessibility support, and a dynamic UI.

🚀 Live Features
✅ Personalized Start Screen

User enters their name

Start button activates automatically

🔄 API-Driven Questions

Fetches 20 MCQs from Open Trivia DB (Category: Computer Science)

Decodes HTML entities for clean readability

Randomizes options per question

🎮 Interactive Quiz System

Highlight correct/wrong answers

Auto-disable options after selection

Keyboard accessibility (Enter / Space)

Next & Finish buttons dynamically enabled

📝 Score & Grade Evaluation

Displays final score

Automatic grade classification:
≥ 90% → Excellent 🎉
≥ 75% → Good Job 👍
≥ 50% → Fair 😐
< 50% → Needs Improvement 😕

🎨 Modern UI

Neon glow card design

Dark theme

Fully responsive

Smooth interactions

▶️ How to Run

Clone the repo:

git clone https://github.com/Hkagarwal1030/Computer-Science-Quiz-App.git


Navigate into the project:

cd Computer-Science-Quiz-App


Open the file in any browser:

index.html


No server required — runs completely client-side.
